# WEB

Repositorio de apuntes y recursos de aprendizaje sobre desarrollo web, herramientas de programación y uso de IA en proyectos prácticos.

## Objetivo

Este proyecto recopila las bitácoras de estudio realizadas durante el curso de web y programación, con foco en:

- fundamentos de la web
- uso de VS Code
- control de versiones con Git y GitHub
- introducción a Python
- IA/LLM, Chatbots y agentes
- desarrollo de apps con Streamlit

## Contenido principal

- [`bitacora1.txt`](bitacora1.txt): conceptos básicos de tecnología web, HTML, CSS, JavaScript, README y diferencias entre editor e IDE.
- [`bitacora2.md`](bitacora2.md): configuración de VS Code, extensiones, Git, GitHub y pasos para publicar un repositorio.
- [`bitacora3.md`](bitacora3.md): introducción a IA, LLM, chatbots, agentes, Python y desarrollo de aplicaciones con Streamlit.

## Notas

- La documentación principal del repositorio se mantiene en archivos de texto y Markdown, priorizando contenido útil y legible.
- Las carpetas de apoyo dentro de `bitacoras/` contienen material complementario como PDFs, scripts y anotaciones textuales.

Puedes abrir cualquiera de las bitácoras con VS Code o cualquier editor de texto. Para ver mejor los archivos Markdown, usa la vista previa de Markdown integrada.

Este repositorio es de carácter educativo y sirve como registro de aprendizaje práctico. Los enlaces de YouTube permiten consultar los videos sin incluir archivos de video en la documentación del repositorio.
