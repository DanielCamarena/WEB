# WEB

Apuntes y recursos de aprendizaje sobre desarrollo web y herramientas de trabajo en VS Code. Este repositorio reúne notas introductorias y una guía práctica para empezar a usar Git y GitHub.

## Contenido

- [`bitacora1.txt`](bitacora1.txt): fundamentos de tecnología web, HTML, CSS y JavaScript; también incluye recursos de aprendizaje y una introducción a los README.
- [`bitacora2.md`](bitacora2.md): notas sobre VS Code, extensiones, Git y los pasos para publicar un repositorio en GitHub.

## Uso

Abre los archivos de notas en cualquier editor de texto. `bitacora2.md` puede verse con formato desde la vista previa de Markdown de VS Code.

Este repositorio es de carácter educativo y, por ahora, no contiene una aplicación que requiera instalación o ejecución.
