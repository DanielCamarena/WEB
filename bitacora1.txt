## ¿Qué es un readme?

En desarrollo de software: documentación de un proyecto es clave
El inicio de la documentación es el readme

## Editor vs IDE

Editor:
Manipular un lenguaje 

Editor sencillo multi-útil -> terminales 
terminal: aplicación sencilla de comandos para el sistema (operativo)

Sistema operativo: mesa sobre la que se colocan los programas de un computador
- permite tener archivos y carpetas

IDE: 
Editor + entorno
Entorno: tener herramientas a la mano
